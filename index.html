一、一句话摘要

Linguist 是一款完全在你自己浏览器里运行的整页翻译扩展，开发者没有服务器。当你翻译网页时，页面文本会通过 HTTPS 直接发往你自己在设置页填写的 OpenAI 兼容接口（默认是 https://api.deepseek.com/v1）。开发者不接收、不存储、也无法访问你的任何数据。

三、我们不做什么

  • 不收集浏览历史，不读取或上传书签、Cookie、密码、表单内容、输入框里的文字。
  • 不设埋点、统计、崩溃上报或远程配置。全扩展只有两个网络调用点（src/core/translator.ts:69 与 :137），两者都指向你自己配置的地址，没有任何写死的第三方/开发者服务器。
  • 不出售、出租或交易你的数据；不用于广告、用户画像、信用评估或贷款决策。
  • 不把数据发给开发者或任何中间服务器；扩展不做二次转发。

四、数据发给第三方时的责任边界（重要，请务必读）

第 2 节第 1、6 项的数据会发送到你自行配置的第三方大模型接口。该接口的运营方如何处理这些数据（是否留存、保留多久、是否用于模型训练、日志与合规策略），由你与该服务商之间的条款决定，不在本扩展的控制范围内。请在使用前阅读对应服务商的隐私政策与数据处理条款。本扩展只负责把请求发到你填写的那个地址，不经过、也不受开发者控制。

如果你使用默认地址 https://api.deepseek.com/v1，请阅读 DeepSeek 的隐私政策；如果你改成别的接口，请阅读对应服务商的政策。

五、API Key 的存储方式与风险（如实说明）

  • 存放位置（确切键名）：chrome.storage.local → 键 settings → 字段 apiKey（src/core/settings.ts:4 定义存储键名，:34 写入；src/core/defaults.ts:5 定义默认空值）。
  • 是否同步到其它设备：不会。用的是 storage.local 而不是 storage.sync。
  • 存储形式：明文。扩展没有做额外加密，也没有云端托管（src/core/settings.ts:34、src/core/defaults.ts:5）。
  • 可见范围：设置页里用 password 输入框显示（src/options/index.html:23）；Key 只在本扩展的请求里使用（src/core/translator.ts:73,141）。
风险如实告知：能读取这台电脑上该浏览器配置目录的人或程序，可以读到这个 Key。这是本地明文存储的固有限制。
建议：请使用可限额、可随时吊销的 Key，不要使用主账号的全权限 Key；一旦怀疑泄露，立刻到服务商后台吊销并更换。

六、数据保留与删除

  • 保留期限：本地数据一直保留，直到你自行删除；没有自动过期机制。
  • 本地只存三个键（确切键名）：settings（设置，含 API Key）、rules（本地规则）、tr:<hash>（译文缓存；tr: 前缀见 src/core/cache.ts:7，键 = 前缀 + hash(提示词版本|源语言|目标语言|模型|原文)，见 :23-26）。
  • 如何删除（当前版本没有内置的「清空译文缓存」按钮，如实说明）：
    1. 移除扩展即清除：在 chrome://extensions（Edge 是 edge://extensions）里移除本扩展，Chrome/Edge 会删除该扩展的全部本地存储（settings、rules、所有 tr:<hash>）—— 这是浏览器在卸载时的行为，不需要你手动清理；
    2. 只删某一类：在该扩展的开发者工具 → Application → Storage → Extension Storage 里，删掉 tr: 开头的键（只清译文缓存）、或 rules（只清本地规则）、或 settings（含 API Key）；
    3. 只想清缓存：删掉全部 tr:<hash> 键即可，settings 与 rules 会保留。
  • 开发者侧：没有任何副本（开发者没有服务器，也收不到任何数据）。

七、权限与数据最小化

当前 public/manifest.json 声明 storage / activeTab / scripting 三个权限与 host_permissions: ["<all_urls>"]；未声明 tabs（也不需要）。每个权限的真实用途、调用点与「是否有冗余」的逐项结论，见仓库里的 store/permission-justification.md。

English Summary

Linguist is a fully local, browser-only page-translation extension. The developer operates no server.

  • What leaves your browser: the page text you choose to translate (sent in batches), plus — only when you use the "AI suggests a rule" feature — a small fact pack for the single block you selected (including up to 300 characters of its source text). Both are sent directly to the OpenAI-compatible endpoint that you configure yourself (default https://api.deepseek.com/v1), using your own API key.
  • What stays local: your API key, settings, your domain preferences, your local layout rules, and a translation cache — all in chrome.storage.local. The cache key is a hash of prompt version/languages/model/source text, so the source text itself is not stored in plaintext.
  • What we never do: no browsing history, no cookies, no bookmarks, no form data, no analytics or telemetry, no ads, no selling or sharing of data with the developer or any third party. The extension makes exactly two network calls, both to the endpoint you configure.
  • Responsibility boundary: the third-party model provider you configure handles retention/training/logging under its own terms. Please review that provider's privacy policy.
  • API key: stored in plaintext in chrome.storage.local. Anyone with access to this browser profile can read it. Use a scoped, revocable key.
  • Deletion: remove the extension, or delete the tr:, rules, settings keys from extension storage. There is currently no in-app "clear cache" button.
